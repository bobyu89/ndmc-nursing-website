# 國防醫學大學護理學院網站 — 設計系統與執行規格

日期：2026-09-14
狀態：使用者已口頭核准方向（做法 C、階段 0 用不啟用測試節點）

## 1. 目標

把護理學院（及學系、研究所，中英共六站）在校方 CMS 內的 html編輯功能頁面，換成一套風格一致、可重複套用的自訂 HTML 版塊。第一個交付物是**護理學院中文首頁**（內容清單 A 列）。

風格定位：莫蘭迪「暖底冷主色」＋ CocoMaterial 手繪插圖，刻意避開藥學院那種「等寬卡片格＋emoji」的 AI 感；同時遵守分析文件的無障礙（AA）、手機優先、文字優先原則。

依據文件（Notion「網站相關分析」）：護理學院架構、受眾需求評估、UI/UX 評估準則、內容清單。架構以「護理學院架構」為準，使用者表示不會大改。

## 2. 硬性約束

### 2.1 來自分析文件
- 不用 emoji 當圖示；圖示一律為圖片並附替代文字（準則七）。
- 首頁文字優先，不做自動輪播；hero 為單張照片＋定位文字＋入口（準則二）。
- 手機優先：段落短、按鈕大、內容兩次點擊內到達（準則八）。
- 避免院內術語（「軍護簡介」「杏網相連」等不出現在標題）。
- 文字對比達 WCAG AA（4.5:1）；莫蘭迪色只用於底色、色塊、插圖填色，不用於內文文字。

### 2.2 來自校方 CMS／前台（實測藥學院頁面）
- 內容區寬度：桌機約 800px（`#contenR.editor` 在 `.sec-main col-lg-9`）；手機為全寬。
- 前台 CSP：`default-src * 'unsafe-inline' 'unsafe-eval' data: blob:` — 外連圖片、內嵌樣式皆允許。
- 站方字型：內容區 `#contenR` 實際為 Microsoft JhengHei 15.75px／行高 25.2px／文字 #1a1a1a，外層白底、內距 30px。不另外載入字型。
- 前台全站載入 **Bootstrap 5.0.2**（`row`／`col-md-*`／`d-none d-md-block`／`order-md-*`／`d-flex`／`p-*`／`shadow-sm` 實測在 `#contenR` 內生效；`rounded-4`、`gap-*` 等 5.2 才有的類別不可用）。
- 因此：不做 hover／捲動動畫；響應式用 **Bootstrap 格線類別＋內嵌樣式**，不寫自己的 media query。

### 2.3 階段 0 實測結果（2026-09-14，測試節點 id 7696「__測試節點（勿啟用）」）
編輯器為 DevExpress ASPxHtmlEditor（`tpl_Html.aspx`，客戶端物件 `hle_templete`，有 `SetHtml/GetHtml`）。客戶端不過濾；**伺服器存檔時過濾**如下：

| 項目 | 結果 |
|---|---|
| 內嵌 `style` 屬性（flex、gap、gradient、aspect-ratio、box-shadow、border-radius、position:fixed、min-width、%寬） | 保留 |
| `class`、`id` 屬性 | 保留 |
| `<h2>` `<div>` `<p>` `<span>` `<a style>` `<ul><li>` `<table>` | 保留 |
| `<img>` 外連 URL、`data:` URI、`alt` | 保留 |
| `<style>` 標籤 | **整段刪除** |
| `<svg>` | **整段刪除**（含內容） |
| `<section>` `<article>` `<details>` `<summary>` | **標籤刪除、文字保留** |
| `role`／`aria-label`（在 svg 上） | 隨 svg 一起消失；其他元素上未測 |

結論：
- 版面用 Bootstrap 5.0.2 類別（響應式）＋內嵌樣式（視覺）。
- 插圖一律 `<img>`：CocoMaterial SVG 上色後以 `data:image/svg+xml;base64` 內嵌，或上傳 CMS 後外連；必附 `alt`。
- 語意標籤只用 `h2–h4`、`p`、`ul/ol`、`table`；不用 section/article/details。
- FAQ 折疊不可行（無 details、無 JS）→ 全展開呈現。
- 測試原始檔：`tools/phase0_test.html`；存檔後讀回：`tools/phase0_result.html`。

### 2.4 首頁實貼結果（2026-09-29，測試節點 7696）
將護理學院首頁（dist/A_home.html，--final）貼入並存檔後讀回，與送出內容逐位元比對，伺服器另外做了兩件事（2.3 未測到）：
- `<i>` 一律改成 `<em>`（class 保留，FontAwesome 以 class 套字型，圖示照常顯示）。
- 所有 `aria-*` 與 `role` 屬性刪除。影響：圖片佔位的 aria-label 消失（佔位內有可見文字，無實質損失）；裝飾元素的 aria-hidden 消失（皆為空元素或 FontAwesome 圖示）。
其餘（inline style 含 clamp()/inset/漸層/outline、class、中文錨點 href、&nbsp;、換行）完全保留。
`build.py` 的 `cms_normalize()` 已在輸出時套用同樣轉換，dist/ 內容即為 CMS 實際儲存內容（首頁 SHA-256 與讀回一致）。
停用（啟用未勾）的節點前台會轉址至校首頁，無法在前台預覽；以 preview/ 代替。

## 3. 視覺系統（初版，階段 1 定稿）

### 3.1 色票（草案，階段 1 以腳本驗證 AA 後定案）
| 用途 | 名稱 | 草案值 |
|---|---|---|
| 頁面底 | 米白 | #F6F3EE |
| 次底／區塊底 | 燕麥 | #EDE7DE |
| 主色面 | 鼠尾草綠 | #8FA69A |
| 主色深（可當文字／按鈕底） | 深鼠尾草 | #3F5A4E |
| 強調面 | 灰粉 | #D9B8B3 |
| 強調深（可當文字） | 深玫瑰 | #8C5A5A |
| 輔助面 | 霧藍 | #B9C6CC |
| 內文 | 深灰褐 | #3B3835 |
| 次要文字 | 灰褐 | #6B655F |

規則：任何文字顏色與其底色的對比必須 ≥ 4.5:1（大字 ≥ 3:1）。「面」色只能當底或填色。

### 3.2 字級與間距
- 字型：繼承站方 Noto Sans TC；英文站同。
- 桌機字級：標題 30–34px／段標 22–24px／內文 16–17px／註 14px；行高 1.7。
- 手機：以 `font-size` 用 px 固定但版面流動，內文不小於 16px。
- 間距節奏：8px 基數（8／16／24／40／64）。

### 3.3 版面性格（taste-skill 三個旋鈕）
- DESIGN_VARIANCE 中：允許左右交錯、寬窄不對稱欄位、插圖出血到區塊邊緣；不做嚴格置中對稱。
- MOTION_INTENSITY 零：技術上不可行也不需要。
- VISUAL_DENSITY 中低：留白多、每屏一個重點。

### 3.4 插圖與照片
- 插圖：CocoMaterial（CC0），以站色重新上色後上傳至 CMS，或以外連 URL／data URI 使用；每張附 `alt`。
- 照片：本階段一律用**佔位框**（燕麥底＋虛線邊＋標示尺寸與用途文字），比例寫死：hero 16:9、特色段 4:3、人物 3:4、消息縮圖 1:1。
- 照片／插圖比例配法待使用者決定（已提出三案，暫以「hero 照片、特色段插圖為主」開發，佔位框可互換）。

## 5. 產出方式（做法 C）

純 Python 3.12、零外部套件。

```
ndmc-nursing-website/
  tokens.py         # 色票、字級、間距；改這裡全站連動
  components.py     # 每個組件一個函式，回傳內嵌樣式 HTML 字串
  pages/            # 每頁一個 .py：呼叫組件並填內容（文字、連結、佔位）
    college_home.py
  build.py          # 產出 dist/<page>.html（可貼版）與 preview/<page>.html
  preview/_frame.html   # 模擬校網外框：800px 內容欄、Noto Sans TC、米白底；另有 375px 手機檢視
  dist/             # 貼進後台用的純內容 HTML（無 html/head/body 標籤）
  tools/check_contrast.py  # 驗證 tokens 中所有文字／底色組合 ≥ AA
  docs/superpowers/specs/   # 本文件與後續規格
```

- `dist/*.html`：只含內容片段，所有樣式內嵌，無 class／style 標籤／svg／script。
- `preview/*.html`：把片段塞進模擬外框，供貼前檢視；用 `tools/serve.ps1` 或直接開檔即可看。
- 內容輸入格式（給內容負責人／使用者）：每頁一份簡單清單——標題、段落文字、連結網址、圖片說明（佔位用）；不需要 HTML 知識。

## 6. 階段與驗收

| 階段 | 內容 | 驗收 |
|---|---|---|
| 0 | 在後台新增一個**不啟用**的測試節點（模組：html編輯功能），貼入測試片段，檢查編輯器保留：內嵌 style／class／`<style>`／`<svg>`／外連 `<img>`／`position:fixed`／flex／data URI | 產出一份「編輯器允許清單」寫進本文件 §2.2 |
| 1 | tokens、components、對比檢查腳本、組件總覽預覽頁 | 使用者看過組件總覽並認可色票與版面性格 |
| 2 | `college_home.py`：以架構文件定位語與內容清單 A 列組首頁，圖片佔位 | 桌機 800px 與手機 375px 預覽皆通過 |
| 3 | 貼進後台測試節點→實機比對→修組件→經使用者確認後再貼到正式「護理學院」L1 節點 | 正式頁與預覽一致；每次貼入前經使用者確認 |
| 4 | 學院站其餘 html 頁（認識本院系列、學術資源系列、招生專區…） | 內容到一頁做一頁 |
| 5 | 學系站、研究所站、三個英文站 | 同組件換內容 |

## 7. 後台操作規範
- 登入一律由使用者本人完成；Claude 不碰帳密。
- 任何新增／儲存／啟用切換前，先在對話中列出將發生的變更並取得確認。
- 貼入後重新讀取頁面確認實際內容（後台 AJAX 面板有時需先「畫面重整」）。
- 詳見個人 skill `ndmc-nursing-cms`。

## 8. 不在範圍
- 校方外框（頂部導覽、左側樹狀選單、頁尾）的樣式。
- 最新消息、表單下載等列表型模組的內容排版（由 CMS 模組決定）。
- 任何需要 JavaScript 的互動。
- 真實照片與插圖的挑選、上色與上傳（本階段以佔位框代替）。
